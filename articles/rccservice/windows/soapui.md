# SoapUI for RCCService

*Credits: SoapUI source author unknown; ! Vand (SoapUI-RS). From ORC Guide.*

Use SoapUI to send SOAP requests to RCCService at `127.0.0.1:64989`. The [thumbnail rendering guide](/article.php?path=infrastructure%2Fapi%2Fthumbnails) includes a basic setup.
