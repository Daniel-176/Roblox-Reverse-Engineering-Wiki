# PHP Libraries for RCCService SOAP

*Credits: BrentDaMage; XlXi (KyleGG). From ORC Guide, December 3, 2025.*

Two PHP libraries for communicating with RCCService over SOAP:

- [PHP-RCCServiceSoap](https://github.com/BrentDaMage/PHP-RCCServiceSoap), by BrentDaMage.
- [virtubrick-grid](https://github.com/RBXC/virtubrick-grid), by XlXi (KyleGG).

The post preferred `virtubrick-grid` and recommended either library.
