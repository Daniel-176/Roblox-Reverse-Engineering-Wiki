# RCCService: Windows, 2015

*Credits: h6di (author), vanilla (2015M RCC). From ORC Guide, July 16, 2026.*

ORC Guide records a 2015M patch for making post-March 2015E clients join.

## Make 2015E Client Join (2015M RCC)

Open RCCService in HxD, search offset `71F040`. You should see `55` in hex, replace with `C3`.

Now 2015E clients can connect.
