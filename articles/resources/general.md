# Resource Archives

Downloadable archives, compiled binaries, and tool repositories for Roblox reverse engineering.

## Archives

- [CoreScripts 2010-2019](/article.php?path=resources%2Fcorescripts): Archive of Roblox CoreScripts from 2010 to 2019
- [RCC & RBXGS Archives](/article.php?path=resources%2Frcc-archives): Archived RCCService and RBXGS installers on the Internet Archive.
- [Roblonium Archive](/article.php?path=resources%2Froblonium-archive): A general roblox archival site
- [Roblox Deployment Downloader](/article.php?path=resources%2Froblox-deployment-downloader): Roblox client download tool and parser that gets client and studio resources from setup.rbxcdn.com.
- [Roblox Client and Studio Archives](/article.php?path=resources%2Fclient-archives): Builds, setup files, and deployment history.
- [2009 Character Content](/article.php?path=resources%2F2009-character-content): Early 2009 avatar assets for rendering with the 2012 client.
- [Legacy Site Images and Textures](/article.php?path=resources%2Fsite-image-archives): Archived website images and Graphictoria textures.
- [R15 Mesh Archive](/article.php?path=resources%2Fr15-meshes): R15 meshes shared with the ORC Guide community.
- [Image Server Suite](/article.php?path=resources%2Fimage-server-suite): Pizzaboxer's greenscreen rendering project.
- [Patching and Script Repositories](/article.php?path=resources%2Fpatching-repositories): External patching guides and legacy Roblox scripts.
- [RbxSigTools](/article.php?path=resources%2Frbxsigtools): Community key-generation and signature utility.
- [Free for Developers](/article.php?path=resources%2Ffree-hosting): Directory of free hosting and developer service tiers.
- [Site Templates](/article.php?path=resources%2Fsite-templates): Roblox API templates for setting up a revival backend.
- [Ultimate Roblox Mobile Archive](/article.php?path=resources%2Fultimate-mobile-archive): ROBLOX iOS mobile clients indexer
- [GT2 Stuff Archive](/article.php?path=resources%2Fgt2-stuff-archive): Large archive (~1-2 TB) of Roblox gt2 client binaries, RCCService versions, and studio builds.

## Version References
