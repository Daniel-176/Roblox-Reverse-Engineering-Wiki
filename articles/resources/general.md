# Resource Archives

Downloadable archives, compiled binaries, and tool repositories for Roblox reverse engineering.

## Archives

- [CoreScripts 2010-2019](corescripts): Archive of Roblox CoreScripts from 2010 to 2019
- [RCC & RBXGS Archives](rcc-archives): Archived RCCService and RBXGS installers on the Internet Archive.
- [Roblonium Archive](roblonium-archive): A general roblox archival site
- [Roblox Deployment Downloader](roblox-deployment-downloader): Roblox client download tool and parser that gets client and studio resources from setup.rbxcdn.com.
- [Roblox Client and Studio Archives](client-archives): Builds, setup files, and deployment history.
- [2009 Character Content](2009-character-content): Early 2009 avatar assets for rendering with the 2012 client.
- [Legacy Site Images and Textures](site-image-archives): Archived website images and Graphictoria textures.
- [R15 Mesh Archive](r15-meshes): R15 meshes shared with the ORC Guide community.
- [Image Server Suite](image-server-suite): Pizzaboxer's greenscreen rendering project.
- [Patching and Script Repositories](patching-repositories): External patching guides and legacy Roblox scripts.
- [RbxSigTools](rbxsigtools): Community key-generation and signature utility.
- [Free for Developers](free-hosting): Directory of free hosting and developer service tiers.
- [Site Templates](site-templates): Roblox API templates for setting up a revival backend.
- [Ultimate Roblox Mobile Archive](ultimate-mobile-archive): ROBLOX iOS mobile clients indexer
- [GT2 Stuff Archive](gt2-stuff-archive): Large archive (~1-2 TB) of Roblox gt2 client binaries, RCCService versions, and studio builds.

## Version References

- [Roblox Version Spreadsheets](version-spreadsheets): Table with all android and iOS clients versions

## Tools

- [GT2 Downloader](gt2-downloader): CLI tool for downloading Roblox clients from GameTest2 endpoint.
