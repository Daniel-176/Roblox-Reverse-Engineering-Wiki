# RbxSigTools

*Credits: lrre-foss community; resource entry by gravity_hq. From Roblox Revival Helpers, June 15, 2024.*

[Download RbxSigTools](https://www.mediafire.com/file/msbfxp1ades6v9j/tools.zip/file)

The tool generates RSA keys and Roblox-style signatures. The June 2024 resource entry says it supports multiple signing formats and has no graphical interface.

The [Windows common patches guide](/article.php?path=client%2Fwindows%2Fcommon-patches) uses `KeyGenerator.exe` from this archive for public-key replacement.
